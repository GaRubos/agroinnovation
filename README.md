# Smakovyy Svit Sousiv

Хочу построить сайт который будет совмещать в себе что-то вроде каталога нашей продукции и лендингом. мы являемся производителями соусов, специй и хотим сделать страницу которая будет одновременно и landing и Katalog нашей продукции. я добавлю тебе наш логотип и добавлю цвета которые мы используем. сайт ориентирован на украинскую аудиторию он должен выглядеть дорого качественно. основная задумка должна быть описано с какими предприятиями мы работаем, добавлю лого, для каталога должны быть категории товаров, карточка товара, внутри фотографии, описание и кнока для связи с менеджером.
